# Security Policy

Security issues affecting NXD or nxdlang.org are taken seriously.
Reporting a Vulnerability

Please do not publicly disclose a suspected security vulnerability through a GitHub issue, discussion, pull request, or other public channel before it has had a reasonable opportunity to be reviewed.

When reporting a vulnerability, please include as much relevant information as possible, including:

    A description of the vulnerability
    Steps required to reproduce it
    The affected component or page
    The potential security impact
    Any known workaround or mitigation

If GitHub private vulnerability reporting is enabled for this repository, please use it for security-sensitive reports.

---

#### Scope

This repository contains the source for the official NXD website and documentation.

Security issues involving the website itself should be reported here.

Issues involving the NXD compiler, language implementation, runtime behavior, or related tooling should be reported to the repository responsible for that component unless disclosure would expose an active security vulnerability.
Public Disclosure

Please allow reasonable time for a reported vulnerability to be investigated and addressed before publicly disclosing technical details.
Supported Versions
nxdlang.org is maintained as a continuously deployed website. Security fixes apply to the current version of the site rather than to separately maintained historical releases.
